# Source provenance

Vision-Language Automated Annotation (VLAA) is a locally extended derivative of
[fengzhizi715/YoloWebAgentStarter](https://github.com/fengzhizi715/YoloWebAgentStarter).
The local repository was seeded at commit
`a593533b63acf2fd9f30736fbc86b5b21fb17ba7` (`Update test_agent_write_tools.py`).
This attribution is retained alongside the original LICENSE and NOTICE.

The inherited NOTICE records an earlier YoloWebAgent source snapshot at
`701f6e5a63b73f39e35f48fb6de7d2414401875a`. The source tree for that earlier
snapshot and a complete original file migration ledger are not available in this
checkout. This document records that inherited statement; it does not independently
verify rights or claim authorization to relicense the material.

The file inventory in [migration_matrix.md](migration_matrix.md) compares the
VLAA source tree with the available Starter seed commit. It is not a reconstructed
Enterprise migration history or a rights grant.

The VLAA additions cover reusable visual workflows, API/local vision adapters,
independent review, editable masks/polygons, LabelMe exchange, project storage,
batch exports, run-history management, and Windows installation/launch tools.
Runtime data, credentials, model weights, research images, local planning notes,
and the inherited promotional image are excluded from the distribution tree.

Upstream authorization remains **pending**. See
[docs/provenance/UPSTREAM_AUTHORIZATION.md](docs/provenance/UPSTREAM_AUTHORIZATION.md).
The maintainer requested a public source repository. Repository visibility does
not establish the missing upstream authorization. Formal tag/release publication
must pass `python scripts/check_release_provenance.py`; no authorization fields
have been filled in or bypassed. Third-party dependency terms remain applicable;
see [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
