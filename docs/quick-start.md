# VLAA 快速入门

完整环境要求与排错见[安装教程](INSTALL.md)，逐步操作见[使用教程](USER_GUIDE.md)。

## 1. 安装并打开

准备 Python 3.12、Node.js 20 或更新版本（推荐 22 LTS），将源码完整解压。

1. 双击根目录 `install.cmd`，联网安装依赖。
2. 双击 `start.cmd`，保留启动窗口。
3. 打开[本地工作台](http://127.0.0.1:5173/)。

也可在源码根目录执行：

```powershell
py -3.12 scripts/setup.py
py -3.12 run.py
```

## 2. 配置模型

进入“设置 → 视觉模型接入”，分别配置并启用候选提出者、独立视觉检查者。支持远端 API 或已启动的本地 HTTP 服务；填写模型名称、接口根地址和必要的密钥，保存后测试图像与坐标。

分割任务需在“SAM 辅助”配置真实可用的本地权重文件。模型、服务与密钥由使用者准备，源码包不包含这些内容。配置保存在本地；“任务助手（Agent LLM）”与工作流视觉角色按用途分别设置。

## 3. 完成一批标注

1. 创建检测或分割数据集，上传图片；已有外部标注可通过 YOLO、COCO 或 LabelMe 导入。
2. 打开“通用图像工作流”，选“用视觉 LLM 标注并检查”。
3. 选择少量图片，创建类别与模型方案。直接添加要识别的类别，填写类别描述和 LLM 全局任务说明。
4. 在“项目与保存位置”新建或选择项目根目录；以后的运行选择该项目会沿用路径。
5. 核对运行预览中的图片、端点、预算与保存位置，启动。
6. 自动处理后逐图复核。选择对象后用画笔、橡皮或多边形补画、修边；无关对象可拒绝。编辑图层旁支持撤销和重做。
7. 保存复核草稿，再处理检查问题、检查全图并确认。全批满足人工确认条件后，模板才继续正式导出或训练评估。

## 4. 保存 JSON 与图片

- **单图**：复核页点“导出 LabelMe JSON”或“保存标注预览 PNG”。完成后显示实际保存位置和下载链接。单图 JSON 可直接保存当前完成的编辑草稿。
- **批量**：先保存各图复核草稿，返回运行页点“批量保存 JSON 与标注图片”。得到逐图结果和 ZIP；清单记录未完成、失败与草稿状态。
- **正式数据**：逐图确认并完成模板导出后点“下载已确认导出”。

LabelMe JSON 含原图，原生掩膜需要 LabelMe 5.8.0 或更新版本。PNG 用于查看标注效果，标注数据请保留 JSON、COCO 或 YOLO 文件。选择项目后，结果自动写入该项目按运行编号区分的目录。

## 5. 训练与继续处理

选择“用已标注图片训练模型”或“标注、训练与持续改进”，核对训练/验证划分、基础权重和设备。训练采用 Ultralytics YOLO，结果可在模型与评估页面查看。后续批次仍需人工确认。

LLM 检查不能保证每个类别与轮廓都正确。先用少量代表性图片验证标注规范、模型接口与实际效果，再扩大处理范围。

运行记录可删除并从“已删除记录”恢复；正在执行的任务需先取消。默认仅绑定本机地址，面向本地单用户。
