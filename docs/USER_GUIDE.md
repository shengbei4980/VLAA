# VLAA 使用教程

以下示例使用虚构的“塔体构件”任务。换成街景、卫星 RGB 图像或其他领域时，分别建立类别与模型方案，沿用相同操作流程即可。

## 先认识几个名称

| 名称 | 是什么 | 你需要做什么 |
| --- | --- | --- |
| 数据集 | 一组图片、类别、标注与训练/验证/测试划分 | 导入图片或已有标注 |
| 类别与模型方案 | 此任务识别哪些类别、遵循哪些规则、用哪些模型 | 为不同研究对象分别保存 |
| 流程模板 | 标注、检查、训练、导出等步骤的组合 | 按目标选择模板 |
| 候选标注/草稿 | 模型建议和你尚未正式确认的修改 | 检查、补画、改类或拒绝 |
| 整图确认 | 你已检查这张图片并正式应用结果 | 保存修改、处理问题后确认 |
| 已确认数据版本 | 本批确认结果的冻结快照 | 后续训练、评估和正式导出使用 |
| 项目根目录 | 一个项目的结果存放位置 | 在运行前选择，以后继续沿用 |

## 1. 选择要做的工作

进入“通用图像工作流”，按页面中的准备步骤操作。

| 页面模板名称 | 适合什么情况 |
| --- | --- |
| 用视觉 LLM 标注并检查 | 还没有识别模型，希望按类别说明让视觉大模型先生成标注 |
| 用已有模型标注并检查 | 已有工作台登记的识别模型，希望批量预标注后人工检查 |
| 用已标注图片训练模型 | 已有标注并完成整图确认，希望训练与评估 |
| 标注、训练与持续改进 | 从预标注开始，在人工确认后继续训练、评估与下一批处理 |

新手建议先选择“用视觉 LLM 标注并检查”，用少量图片走通整个流程。通用视觉自动流程支持检测和实例分割；数据集模块也支持旋转框与图像分类，需选择匹配的标注和训练流程。

## 2. 准备图片与已有标注

在数据集页面新建数据集并选择任务类型，上传图片，再到工作流选择本批图片。检测用矩形框表达对象；分割用对象轮廓或像素掩膜表达对象。

已有外部标注时，可通过导入中心导入 YOLO、COCO 或 LabelMe ZIP。先预览、确认任务类型并映射类别。外部导入结果也需要在本工具中复核确认后，才能用于要求人工确认的训练流程。

训练任务需要合理划分 `train`、`val`、`test`。训练集用于学习，验证/测试图像用于衡量模型对未参与训练图片的表现。来自同一场景的相近图片应结合研究设计划分，避免仅凭训练集效果判断精度。

## 3. 配置视觉模型

在“设置 → 视觉模型接入”分别配置：

- **候选提出者**：看图找对象，给出类别与位置建议。
- **独立视觉检查者**：再次核对错类、漏标与边界。两个角色可分别配置服务与模型。

选择远端 API 或本地 HTTP 服务，填入支持图片输入的模型名称、API Base URL、认证方式和密钥。保存后运行“测试图像与坐标”。密钥留空会保留已有值；本地服务是否需要密钥由服务配置决定。

“任务助手（Agent LLM）”是用于问答、诊断和提交受控任务的对话助手。通用工作流的视觉标注与检查使用本节的两个视觉角色配置。

### 分割任务还要配置 SAM

进入“设置 → SAM 辅助”，启用 SAM，填写已下载的兼容权重文件路径并选择设备。工作流分割要求真实可用的本地权重文件；首次运行前完成下载与配置。视觉 LLM 提供对象语义与位置，SAM 根据提示生成对象轮廓。

框选和正负点也可在人工编辑时辅助重做选中对象的轮廓。检查生成结果后再保存；仅供复核的框形回退建议不能作为准确分割结果。

### 原图与坐标如何处理

原始图片保留，最终标注以原图绝对像素保存。视觉设置中的“最大图像边长”控制发送给视觉服务的副本：图片超过此值才缩小发送。

例如 2400×2000 图片，将两个角色的最大图像边长分别设为 2400 或更大，可按原尺寸发送，前提是服务本身支持该尺寸。模型原生坐标格式可选像素、0–1、0–1000，应与所用服务匹配。工具负责转换和校验；原尺寸发送仍需正确的坐标声明与实际返回，不能替代坐标测试。

## 4. 定义本次要识别的类别

在“设类别与模型”中，新建或选择一个方案：

1. 设置任务类型：例如“实例分割”。
2. 在“要识别的类别”中手动添加类别，例如“塔身”“塔檐”。无需先有标注，也可以从已有数据集读取类别。
3. 不需要的类别可单独删除。运行后使用冻结的类别列表，修改类别规则后应新建一次运行。
4. 为容易混淆的类别填写“怎样识别这个类别”，必要时补充正例、反例和别名。
5. 填写“LLM 的全局任务说明”，说明本批共用的边界、排除对象与标注规则。
6. 保存方案。卫星 RGB 等新任务另建方案，设置自己的类别与尺度要求。

塔体构件的全局说明示例：

> 仅标注类别列表中的塔体构件。逐个标注可见实例，边界沿实际可见轮廓。被遮挡部分不猜测补全。树木、行人、文字和背景建筑不属于本次目标。

卫星 RGB 图像可另设“建筑物”“道路”等类别，并明确阴影、遮挡、道路交叉口和相邻建筑的处理方法。说明应与你的研究标注规范一致。

类别说明能约束模型，但仍可能出现未归类候选。复核时应把目标映射到本次类别，把无关候选拒绝；不要为了通过检查把无关内容强行改成目标类别。

## 项目与保存位置

在运行前的“项目与保存位置”中选择已有项目，或填写名称和完整根目录，例如：

```text
项目名称：塔体构件试验
项目根目录：E:\VLAAProjects\Tower
```

点击“保存项目并使用”。以后在“本次使用的项目”选择同一项目，会继续沿用该根目录。根目录应是你有写入权限的文件夹。

每次运行独立安排结果：

```text
项目根目录/
  workflow-<运行编号>/
    annotations/
      json/            LabelMe JSON
      images/          标注预览 PNG
      ...zip           批量导出包
      ...              该流程的其他标注导出产物
    models/            训练模型产物
    evaluations/       评估产物
```

具体文件名与目录以运行预览、导出回执显示为准；只有执行了相应步骤才会产生对应文件。下一批使用自己的运行目录，继承所属项目。

选择项目时，本次输出优先使用项目目录，方案中另设的输出路径由项目目录接管。未选择项目时，使用工作台/方案的输出设置；单图 JSON 与 PNG 还可在“JSON 与标注图片的保存位置”设置各自默认目录。工作台数据根目录用于数据库、设置和受管数据，与项目结果目录分别管理。

## 5. 预览并启动

核对图片范围、任务类型、类别、模型、请求预算、修正次数、项目输出路径与后续步骤。远端 API 会接收本批处理图片，预览会列出目的端点。勾选已核对后启动。

运行页显示每一步状态和错误。自动标注完成后会停在人工检查步骤，不会仅凭 LLM 的检查结论直接把草稿当作训练真值。

修正次数与请求预算限制自动处理范围。预算耗尽、无法修复或接口失败时，查看步骤信息，修正配置或人工处理后再按页面允许的操作继续。更换服务或权重前先结束当前批次，重新预览新运行。

## 6. 复核：补画与调整已有轮廓

在运行页面打开一张图片，进入“图像复核”。右侧对象列表与画布编号对应。

### 示例：补齐对象 #3 的漏标部分

1. 点击右侧 **#3**，确认该对象处于选中状态。
2. 编辑图层选择“对象掩膜”。
3. 较小缺口：选“画笔”，调整半径，在遗漏部分涂画；多余区域用“橡皮”擦除。
4. 较大遗漏：选“多边形”，用途选“补全选中对象”，沿漏掉部分逐点围出闭合区域。可适当覆盖已有对象边缘以连接轮廓。
5. 点击“完成轮廓”、起点、双击，或按 Enter 完成。用途为“擦除选中区域”时会减去围出的区域。
6. 点击画布旁的“保存修改”。看到“当前修改已保存至工具”后，可离开页面，以后从数据集的“继续 LLM 标注复核”重新打开。页面顶部的“保存复核草稿”也可保存相同内容。继续检查其他对象，完成后导出或整图确认。

补画只改变选中对象。重新生成整个对象轮廓可用 SAM 框选或正负点，完成后仔细检查原本正确的区域。

### 新增漏掉的对象

选择“当前绘制类别”，点击“新增漏标对象”，沿对象轮廓逐点绘制，最后“完成轮廓”。这是创建新实例；补齐已有对象应先选中已有实例。

### 调整顶点与撤销

- 对具有可编辑顶点的原生多边形，选“编辑顶点”后拖动顶点；双击边可插入顶点，选中顶点后 Delete 可删除。
- 像素掩膜用画笔、橡皮或多边形增减区域调整；这类对象没有原生多边形顶点可拖动。
- “编辑图层”旁的“撤销上一步”“重做上一步”作用于已完成的修改。
- 绘制中的多边形可按 Backspace 撤回一点，Esc 取消；绘制结束或取消后才能保存、导出或切换编辑目标。
- 放大后可滚动检查细节；调低叠加透明度或关闭对象叠加可对照原图。

### 类别、无关候选与检查问题

目标类别不正确时在对象卡片选择正确类别。无关对象点击“拒绝对象”；未归类候选也可使用页面提供的批量拒绝操作，执行前确认它们确实都不属于本次目标。

“检查问题”列出视觉服务提出的语义疑问。逐项选择裁决并填写理由；有批量结论入口时，也应确认该结论适用于所选问题。类别未确定、几何无效等确定性问题需要修改对象或拒绝对应候选，再保存草稿刷新检查。

“阻塞”表示正式确认条件还没满足，例如某对象未确定类别、轮廓无效或问题尚未裁决。根据列表处理即可；当前合法草稿仍可先导出 LabelMe JSON。

## 7. 保存与导出 JSON、图片和批量结果

| 你需要什么 | 在哪里点 | 保存的内容 |
| --- | --- | --- |
| 单张标注 JSON，继续用 LabelMe 编辑 | 复核页顶部“导出 LabelMe JSON” | 当前完成的编辑与原图，保留草稿/已确认状态 |
| 单张带颜色轮廓的图片 | “保存标注预览 PNG” | 原图尺寸的当前标注叠加效果 |
| 一批 JSON 和预览图 | 返回运行页，“批量保存 JSON 与标注图片” | 本批已保存复核结果、PNG、ZIP 与清单 |
| 正式标注数据 | 完成整图确认与模板导出后，“下载已确认导出” | 方案中选定且适配任务的格式 |
| 单张正式 COCO 数据 | 整图确认后的“下载本图 COCO 标注” | 原图和正式标注，分割可保留 RLE 掩膜 |

### 单图 LabelMe JSON

点击“导出 LabelMe JSON”后，页面会显示实际保存位置。需要浏览器下载副本时，再点“下载 JSON”。JSON 包含原图，可以直接在兼容的 LabelMe 中打开；掩膜形状需要 **LabelMe 5.8.0 或更新版本**。

已完成的未保存修改也可导出为单图草稿。未闭合的绘制先完成或取消。有效且已匹配类别、未拒绝的对象进入标注形状；未归类候选与待复核状态保留在复核元数据中，供检查，不会自动新增类别。

PNG 用于查看与展示标注效果。继续编辑或训练时，请同时保留 JSON/COCO/YOLO 等标注数据。

### 批量保存

批量导出读取服务器上**已保存**的复核结果。请先在各图片保存草稿，再回运行页点击批量保存。允许先保存已经完成的图片，其余图片处理好后再次导出。

导出结果显示成功、草稿、失败、跳过数量，以及每张图片的实际路径与原因。单张失败时会继续处理其他图片；根据列表修复后重新保存。ZIP 内包含 `json/`、`images/` 和 `manifest.json`，清单关联原文件名、图片编号、修订与状态。通过图片编号区分同名图片。

项目目录已选定时，单图和批量结果自动沿用本次项目路径。每次保存仍需看页面回执，确认文件已写入目标位置。

### 选择格式

检测/分割可根据用途选择 LabelMe、COCO 或适配的 YOLO 格式。LabelMe 便于外部继续编辑；COCO RLE 与 LabelMe 掩膜适合需要保留孔洞、分离区域的标注。

YOLO 多边形无法完整表达部分掩膜结构。遇到几何损失阻塞时，选能保留掩膜的格式，或按任务要求修正对象；不要通过忽略错误把不准确的几何当作准确标注。

## 8. 确认后训练、评估与下一批

保存复核草稿后，完成问题裁决，检查对象类别、边界、漏标与有效范围。勾选“我已检查全图…”后点击“确认整图并应用”。没有目标时按页面入口确认无目标；需排除的图片按页面要求填写理由。

一张图片确认后，本批仍会等待其他纳入图片。全部满足人工关卡后，流程创建冻结数据版本；选择了训练模板才会继续训练和评估。

本地训练使用 Ultralytics YOLO。训练参数、基础权重、设备和 split 需符合任务。模型库可以查看训练产物与评估结果；下一批流程只有满足预设范围、质量条件和预算时才继续，后续标注仍需人工确认。

第一版模型精度不足时，应优先修正与补充训练样本、检查类别规范、比较验证集指标，再决定是否扩大自动预标注。LLM 提交一次自动标注申请不会直接提高原识别模型精度；视觉 LLM 的独立检查提供额外线索，最终仍要检查标注。

## 9. 管理运行记录

在“运行记录”点击“删除记录”。仍在运行或等待人工处理的任务会要求“取消任务并删除记录”，任务取消并结束输出操作后才可删除；等待期间按页面提示检查状态。

删除会把记录移入“已删除记录”，可在那里“恢复记录”。已有关联标注、模型和导出文件保留，恢复记录也不会重新执行已取消的任务。批量结果和本地文件的整理应根据实际路径另行管理。
